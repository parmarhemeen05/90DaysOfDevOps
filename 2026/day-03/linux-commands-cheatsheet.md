LInux Command Cheatsheet
1.ls:-It is used to list out all files
2.pwd:-It is used to show current directory files 
3.cd:-It is used to change directory
4.cp:-It is used to copy the file
5.mv:-It is used to move the file
6.mkdir:-It is used to make a new directory
7.rmdir;-It is used to remove the directory
8.touch:-It create an empty file
9.head:-It show begining of file
10.tail:-It show end of file 
11.df:-It is used to display space usage in device
12.ps:-It display currently running process
13.kill:-It terminate the process by (PID=1)
14.ping:-It check the connection of network host 
15.ip addr:-It shows ip address
